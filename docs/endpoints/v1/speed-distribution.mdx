# Speed Distribution

Distribution of speeds across the track for all drivers or a specific driver.

<EndpointCard method="GET" path="/api/v1/speed-distribution-plot" description="PNG speed distribution histogram." />
<EndpointCard method="GET" path="/api/v1/speed-distribution-data" description="JSON speed distribution data." />

## Parameters

<ParamTable
  params={[
    { name: 'year', type: 'integer', required: true, description: 'Race season year (2018–2030)' },
    { name: 'gp', type: 'integer', required: true, description: 'Grand Prix round number (1–24)' },
    { name: 'session', type: 'string', required: true, description: 'Session type: Q, R, FP1, FP2, FP3, S, SQ' },
    { name: 'driver', type: 'string', required: false, description: '3-letter driver code (e.g. VER). Omit for all drivers.' },
  ]}
/>

```bash
curl "https://api.t1f1.com/api/v1/speed-distribution-data?year=2025&gp=1&session=Q" \
  -H "X-API-Key: YOUR_KEY"
```
