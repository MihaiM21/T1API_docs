# Qualifying Results

Qualifying session results including best lap times, tyre compounds, and session segments (Q1/Q2/Q3).

<EndpointCard method="GET" path="/api/v1/qualifying-results-plot" description="PNG qualifying results chart." />
<EndpointCard method="GET" path="/api/v1/qualifying-results-data" description="JSON structured qualifying results." />

## Parameters

<ParamTable
  params={[
    { name: 'year', type: 'integer', required: true, description: 'Race season year (2018–2030)' },
    { name: 'gp', type: 'integer', required: true, description: 'Grand Prix round number (1–24)' },
    { name: 'session', type: 'string', required: true, description: 'Use Q for qualifying' },
  ]}
/>

```bash
curl "https://api.t1f1.com/api/v1/qualifying-results-data?year=2025&gp=1&session=Q" \
  -H "X-API-Key: YOUR_KEY"
```
