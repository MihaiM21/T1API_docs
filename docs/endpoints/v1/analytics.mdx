# Analytics

Aggregate usage and session statistics generated by the V1 pipeline.

<EndpointCard method="GET" path="/api/v1/analytics/daily" description="Daily session statistics and request counts." />
<EndpointCard method="GET" path="/api/v1/analytics/total" description="Cumulative analytics across all processed sessions." />

## Parameters

<ParamTable
  params={[
    { name: 'date_str', type: 'string', required: false, description: 'Date filter in YYYY-MM-DD format. Defaults to today.', default: 'today' },
  ]}
/>

```bash
curl "https://api.t1f1.com/api/v1/analytics/daily" -H "X-API-Key: YOUR_KEY"
curl "https://api.t1f1.com/api/v1/analytics/total" -H "X-API-Key: YOUR_KEY"
```

```json title="GET /api/v1/analytics/daily"
{
  "date": "2026-06-21",
  "total_sessions": 9,
  "top_speed_sessions": 4,
  "throttle_sessions": 1,
  "qualifying_sessions": 1,
  "track_comparison_sessions": 1,
  "last_updated": "2026-06-21 15:10:54"
}
```
