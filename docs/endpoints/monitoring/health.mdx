# Health Check

Public endpoint — no API key required. Returns the operational status of the API and its connected services.

<EndpointCard method="GET" path="/api/health" description="Health check — public, no auth required." />

```json title="GET /api/health"
{
  "status": "healthy",
  "version": "1.5.0",
  "environment": "production",
  "checks": {
    "api": "healthy",
    "mongodb": "healthy",
    "session_tracker": "healthy",
    "background_processor": "running",
    "processed_sessions": 0,
    "environment": "production"
  }
}
```
