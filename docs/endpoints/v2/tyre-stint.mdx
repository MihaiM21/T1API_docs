# Tyre Stint Strategy

Timeline of each driver's tyre stints across a race — compound, start lap, and end lap.

<EndpointCard method="GET" path="/api/v2/tyre-stint-usage-plot" description="PNG timeline of tyre stints per driver." />
<EndpointCard method="GET" path="/api/v2/tyre-stint-usage-data" description="JSON per-stint records for all drivers." />

## Parameters

<ParamTable
  params={[
    { name: 'year', type: 'integer', required: true, description: 'Season year (2018–2026)' },
    { name: 'gp', type: 'integer | string', required: true, description: 'Round number, event key, or event name' },
    { name: 'session', type: 'string', required: true, description: 'Session type — typically R' },
  ]}
/>

```bash
curl "https://api.t1f1.com/api/v2/tyre-stint-usage-data?year=2025&gp=1&session=R" \
  -H "X-API-Key: YOUR_KEY"
```

<Callout variant="info">
V2 endpoints require the session to be in the livetiming cache. The example uses gp=4 (Bahrain GP).
</Callout>

```bash
curl "https://api.t1f1.com/api/v2/tyre-stint-usage-data?year=2025&gp=4&session=R" \
  -H "X-API-Key: YOUR_KEY"
```
