# Lap Times Distribution

Per-lap breakdown of lap times and tyre compound for a single driver across a race session. Useful for stint analysis and tyre degradation visualisation.

<EndpointCard method="GET" path="/api/v2/laptimes-distribution-data" description="JSON per-lap times with compound for a single driver." />

## Parameters

<ParamTable
  params={[
    { name: 'year', type: 'integer', required: true, description: 'Season year (2018–2026)' },
    { name: 'gp', type: 'integer | string', required: true, description: 'Round number, event key, or event name' },
    { name: 'session', type: 'string', required: true, description: 'Session type — typically R' },
    { name: 'driver', type: 'string', required: true, description: 'Driver TLA (e.g. VER)' },
  ]}
/>

```bash
curl "https://api.t1f1.com/api/v2/laptimes-distribution-data?year=2025&gp=1&session=R&driver=VER" \
  -H "X-API-Key: YOUR_KEY"
```

<Callout variant="info">
V2 endpoints require the session to be in the livetiming cache. The example uses gp=4 (Bahrain GP).
</Callout>

```bash
curl "https://api.t1f1.com/api/v2/laptimes-distribution-data?year=2025&gp=4&session=R&driver=VER" \
  -H "X-API-Key: YOUR_KEY"
```
