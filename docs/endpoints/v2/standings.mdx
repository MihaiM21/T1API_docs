# Championship Standings

Drivers and constructors championship standings — current season, a complete season, or standings after a specific round.

<EndpointCard method="GET" path="/api/v2/standings/drivers" description="Latest drivers championship standings." />
<EndpointCard method="GET" path="/api/v2/standings/constructors" description="Latest constructors championship standings." />
<EndpointCard method="GET" path="/api/v2/seasons/{year}/drivers-standings" description="Drivers standings for a complete season." />
<EndpointCard method="GET" path="/api/v2/seasons/{year}/constructors-standings" description="Constructors standings for a complete season." />
<EndpointCard method="GET" path="/api/v2/seasons/{year}/round/{round_nr}/drivers-standings" description="Drivers standings after a specific round." />
<EndpointCard method="GET" path="/api/v2/seasons/{year}/round/{round_nr}/constructors-standings" description="Constructors standings after a specific round." />

## Current standings

No parameters required. Automatically resolves to the current season, or the previous season if the current one has not yet begun.

```bash
curl "https://api.t1f1.com/api/v2/standings/drivers" -H "X-API-Key: YOUR_KEY"
curl "https://api.t1f1.com/api/v2/standings/constructors" -H "X-API-Key: YOUR_KEY"
```

## By season or round

<ParamTable
  params={[
    { name: 'year', type: 'integer', required: true, description: 'Season year (path parameter)' },

```bash
# Full 2024 season
curl "https://api.t1f1.com/api/v2/seasons/2024/drivers-standings" -H "X-API-Key: YOUR_KEY"

# After Round 10 of 2024
curl "https://api.t1f1.com/api/v2/seasons/2024/round/10/drivers-standings" -H "X-API-Key: YOUR_KEY"
```
