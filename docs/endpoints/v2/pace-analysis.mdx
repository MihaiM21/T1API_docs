# Pace Analysis

Box-and-whisker lap time distribution per driver or per constructor across all valid laps in a session. Laps outside 107 % of the session's quickest time are filtered out to remove outliers (in-laps, out-laps, safety car laps).

<EndpointCard method="GET" path="/api/v2/driver-pace-plot" description="PNG pace distribution box plot per driver." />
<EndpointCard method="GET" path="/api/v2/driver-pace-data" description="JSON statistical pace distribution per driver." />
<EndpointCard method="GET" path="/api/v2/teams-pace-plot" description="PNG pace distribution box plot per constructor." />
<EndpointCard method="GET" path="/api/v2/teams-pace-data" description="JSON statistical pace distribution per constructor." />

## Parameters

<ParamTable
  params={[
    { name: 'year', type: 'integer', required: true, description: 'Season year (2018–2026)' },
    { name: 'gp', type: 'integer | string', required: true, description: 'Round number, event key, or event name' },
    { name: 'session', type: 'string', required: true, description: 'Session type — typically R' },
  ]}
/>

```bash
# Driver pace
curl "https://api.t1f1.com/api/v2/driver-pace-data?year=2025&gp=1&session=R" \
  -H "X-API-Key: YOUR_KEY"

# Team pace
curl "https://api.t1f1.com/api/v2/teams-pace-data?year=2025&gp=1&session=R" \
  -H "X-API-Key: YOUR_KEY"
```

<Callout variant="info">
V2 endpoints require the session to be in the livetiming cache. The examples use gp=4 (Bahrain GP).
</Callout>
