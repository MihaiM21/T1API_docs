# Lap Time Analysis

Speed, cumulative delta time, and Throttle vs. distance for two drivers' fastest laps. The delta trace shows time gained or lost relative to the reference driver at each point on the track.

<EndpointCard method="GET" path="/api/v2/lap-time-analysis-plot" description="PNG plot of Speed, Delta, and Throttle vs. distance for two drivers." />
<EndpointCard method="GET" path="/api/v2/lap-time-analysis-data" description="JSON Speed, Throttle, and delta-time series for both drivers." />

## Parameters

<ParamTable
  params={[
    { name: 'year', type: 'integer', required: true, description: 'Season year (2018–2026)' },
    { name: 'gp', type: 'integer | string', required: true, description: 'Round number, event key, or event name' },
    { name: 'session', type: 'string', required: true, description: 'Session type (default: Q)' },
    { name: 'd1', type: 'string', required: true, description: 'Reference driver TLA (e.g. NOR)' },
    { name: 'd2', type: 'string', required: true, description: 'Comparison driver TLA (e.g. VER)' },
  ]}
/>

```bash
curl "https://api.t1f1.com/api/v2/lap-time-analysis-data?year=2025&gp=4&session=Q&d1=NOR&d2=VER" \
  -H "X-API-Key: YOUR_KEY"
```

<Callout variant="info">
V2 endpoints require the session to be in the livetiming cache. The example uses gp=4 (Bahrain GP).
</Callout>
