# Speed Distribution

Speed distribution across the full session sourced from the V2 direct client.

<EndpointCard method="GET" path="/api/v2/speed-distribution-plot" description="PNG speed distribution from V2 telemetry." />
<EndpointCard method="GET" path="/api/v2/speed-distribution-data" description="JSON speed distribution from V2 telemetry." />

## Parameters

<ParamTable
  params={[
    { name: 'year', type: 'integer', required: true, description: 'Race season year (2018–2030)' },
    { name: 'gp', type: 'integer | string', required: true, description: 'Round number, event key, or official name' },
    { name: 'session', type: 'string', required: true, description: 'Session type' },
  ]}
/>

<Callout variant="info">
V2 endpoints source data from the F1 livetiming cache. The example below uses gp=4 (Bahrain GP) where data is available.
</Callout>

```bash
curl "https://api.t1f1.com/api/v2/speed-distribution-data?year=2025&gp=4&session=Q" \
  -H "X-API-Key: YOUR_KEY"
```
